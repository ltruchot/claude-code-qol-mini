# qol-mini

Minimal kit for [Claude Code](https://code.claude.com): a context gauge, sounds, a
tab marker and a review before `/compact` for every project; skills per project.

```bash
pnpm dlx qol-mini install                              # global: hooks and status line
pnpm dlx qol-mini skills install qa-pr ./my-project    # project: skills
pnpm dlx qol-mini --help
```

Node.js 22.18+. Documentation:
[github.com/ltruchot/claude-code-qol-mini](https://github.com/ltruchot/claude-code-qol-mini#readme).
